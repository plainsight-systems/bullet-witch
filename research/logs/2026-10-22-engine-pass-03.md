# Engine pass 03 — actors and particles

## Checkpoint 1: original type and asset evidence

Continued the documentation milestone; rendering remains deferred. All game reads
are read-only and outputs remain under research.

- Added `tools/particle_survey.py`: surveyed all 6,625 CPR headers/names and recovered
  MSVC x86 RTTI candidates from the hash-checked unpacked analysis copy.
- Original `cgl` names identify sprite, cross, trace, two-point trace and model
  effect parts, including motion model particles. 51 matching RTTI descriptors,
  41 with candidate vtables; these counts are not counts of unique particle types.
- Metadata filter selected 872 members: four `effect_pack.bin` files and five
  stage `effect.emt` members among them. Packs begin `KPKd`; stage files `EVMT`.
- Exported 121 functions with Ghidra 12.1.4, preserving instructions and references
  in `evidence/engine/pass-03a/`; exact command and environment are beside exports.
- Confirmed `_SetEffectWorkSize` reaches initialization at 0x6084f0 through owner
  +0x6148c. The value is bytes after a 20-bit shift in the Lua callback.
- Confirmed 0x418f20 assembles character resources, while `_SetEnemy` reaches
  0x47ef40, a separate group/chara table-driven spawn path.

- Added `tools/effect_pack_inventory.py`. Checked independent CPR offsets, payload
  bounds and every nonnegative effect-to-part and part-to-definition index.
- Recovered 585 effect entries, 1,640 part records, 833 definitions; 583 distinct
  stored IDs (7 and 12000 repeat). Definition type counts: 703 sprite, 122 model,
  1 type-2 trace, 7 type-5 trace. Cross and two-point code exists, with zero such
  definitions in these four packs.
- Native factory 0x50f900 and update chain 0x45f070 -> 0x608890 -> 0x52e8e0 ->
  0x52e320 -> part virtual +0xc establish simulation routing. Representative sprite
  methods identify age/expiry, geometry output, distance sorting/fading and basis work.
- Five EVMT members contain 25 sequence entries. Connected the embedded +0xb0
  sequence object through vtable 0x837770 to 0x4dbee0 -> 0x510b50 particle creation.
- Three slices export 292 function rows / 257 distinct addresses, all successful.
  Pseudocode recovery artifacts remain explicitly identified; no runtime execution.
